# Movie Rental Store Analytics Capstone  

## Data-Driven DVD Rental Store Optimization: SQL, Excel, and Power BI Analysis  

This **Movie Rental Analytics** capstone project explores the **Sakila Dataset** to provide actionable insights for DVD rental store optimization. Using **SQL, Excel, and Power BI**, we analyze customer behavior, film performance, staff productivity, and revenue trends to support strategic decision-making and operational improvements.  

## 📋 **Prerequisites**  
- **Excel** (for data cleaning & analysis)  
- **SQL** (for database querying)  
- **Power BI** (for visualization & dashboarding)  
- **Problem-Solving Skills** (for deriving insights)  

---

## 🚀 **Project Overview**  

### **Problem Statement**  
This project aims to develop a **Power BI dashboard** using the **Sakila DVD Rental Store Database** to:  
- Analyze **customer behavior** and preferences.  
- Evaluate **film performance** and inventory trends.  
- Assess **staff productivity** and operational efficiency.  
- Identify **revenue patterns** for business growth.  

The goal is to help rental store owners **optimize inventory, improve customer satisfaction, and enhance business performance**.  

---

## 📊 **Dataset Description**  
The **Sakila Dataset** contains relational data on:  
- **Films & Categories** (rental rates, popularity, genres)  
- **Customers & Rentals** (demographics, rental history)  
- **Staff & Stores** (employee performance, store locations)  
- **Payments & Revenue** (financial trends, profitability)  

This dataset serves as the foundation for **data exploration, SQL analysis, and Power BI visualizations**.
